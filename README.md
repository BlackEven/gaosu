# gaosu

## 演示页面（综合态势 A 模块）

- **入口**：`demo/overview/index.html`
- **打开方式（任选其一）**：
  - 直接用浏览器打开该 HTML 文件
  - 或在仓库根目录启动静态服务（推荐，避免浏览器跨域限制）：

```bash
python3 -m http.server 8000
```

然后访问：`http://localhost:8000/demo/overview/`

## 演示能力（已实现）

- **三维（倾斜视角）底图**：网格+地形起伏+高速公路带（演示占位）
- **综合态势要素**：机场位置/状态/覆盖、无人机实时位置/状态、航线（可切换）、近5分钟航迹
- **底部时间轴**：实时/回放、播放/暂停、倍速
- **多屏直播**：2/4/6 分屏（模拟画面），点击分屏联动地图定位
- **虚拟座舱**：HUD（电量/链路/速度/高度/航向/航点/ETA）+ 强告警置顶
